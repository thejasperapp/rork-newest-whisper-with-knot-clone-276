## Amendment to merge

### Failure to avoid

A successful Markdown → HTML → PDF conversion does not fulfill an original request for a Markdown file. Likewise, a PDF is not acceptance for a TXT, HTML, CSV or DOCX request. Intermediate source format, a remembered procedure and a renderer default never override the requested final output. A renamed PDF is not a raw-format file.

### Procedure

1. Bind the final format from the current original request before authoring. Distinguish source/reference mentions from the requested output. For ambiguous or unsupported named formats, ask for a choice or stop honestly; never silently substitute PDF. Use PDF only for an explicit PDF request or an unnamed readable-document request.
2. Read the actual indexed live guide, relevant resident guidance and indispensable original/reference content completely. A catalog, filename, old memory record or prior delivery is not the content of a source, proof of current bytes or permission to reuse an old final.
3. For TXT, MD, HTML, CSV and JSON, author a new complete UTF-8 final directly with its requested extension. Keep Markdown as Markdown, HTML self-contained and CSV rows/columns/values intact. Do not run these outputs through a PDF converter. A raw file has one logical-file count, not rendered-page proof.
4. For PDF and supported Office outputs, retain the distinct measured source, live-agent conversion, independent every-page structure/render/text proof and complete original-request/source-versus-final comparison. Do not conflate source completeness with final proof or factual/visual certification.
5. Use fresh task-owned paths and preserve every existing/rejected file. Only positive explicit named retrieval may inspect an old final; editing/creation, negative mentions, inventory and archives are not retrieval permission. Preserve ownership, consent, Stop, the twelve-command/three-skill caps and no replay of failed, incomplete or uncertain work.
6. Require measured execution, complete saved-byte rehash, independent complete-content comparison against the original ask and actual complete sources, and immutable private capture. A manifest, path, rendering success or promised link alone is not delivery. Keep the requested format consistent through workspace final, capture, attachment card, original download and share/save.
7. Record acceptance against the ORIGINAL request, not a more convenient substituted task. Report actual captured format, MIME, byte identity and observed comparison/proof scope. If any required evidence is absent, label that acceptance pending or failed; do not turn a PDF conversion into “Markdown delivered.” Optional learning or memory cannot reopen finished work or invent acceptance.
