# Creator Analytics

Keep dated observations separate from guesses. A partial visible list is not a complete audience, and last month's count is not a current count.

## Reading discipline

1. Give every number its actual as-of date. Memory records retain that date; an old observation is labeled historical, never repeated as now.
2. Name coverage and order. For example, 414 visible accounts out of a count of 516, newest first, is a window, not a complete list. Do not infer an unfollow from a name falling off its edge or diff two partial windows as complete sets.
3. Distinguish count change, observed list churn and post performance. A count change does not identify who followed or unfollowed. Stable counts can hide churn but never prove particular identities.
4. Separate observation from explanation. Do not invent reach, impressions, following counts, follower names, causes, post contents or external-account access that the actual surface did not return.

## Material reporting

- For an approved recurring creator check, report follower-count movement of at least five accounts or one percent of the last reported count, whichever is larger. Small movements accumulate against the last reported baseline; do not reset that baseline after every quiet check.
- A newly exceptional post at roughly twice the observed recent median can be material when both the post and a usable nonzero median are actually available. A still-exceptional post is not new merely because its totals grew slightly. Report a decline or velocity only when comparable dated observations actually establish it.
- Following-count changes, recognized new followers or account-specific trends require the corresponding actual permitted data. The current narrow creator reader does not provide following lists or identities; do not fabricate them to satisfy this guide.
- One useful report per firing; unchanged successful checks remain quiet. Unavailable/failed reads stay failures, never zero snapshots or no-change success.

## Existing scope wins

The currently approved own-account reader supplies newest 100 authored posts in a thirty-day publication window, current like/comment totals and follower count, with an explicit coverage limit. These are current totals on those posts, not interactions occurring only during thirty days and not reach. Creator-score monitoring is an estimate; basic Analytics and verified/staff Creator Studio access differ. A connected account or this guide does not authorize new private reads.

Use the responsibility's existing durable owned baseline for scheduled comparisons; do not write global workspace MEMORY.md from a background check. Conversational notes may record only actually observed dated facts through authorized turn-close memory handling. No skill can create or expand a responsibility, grant or schedule.

## Report

Say what changed, by how much, since which actual observation, and any evidenced driver. Include as-of and coverage. Ground recommendations in the returned metrics, not presumed algorithm behavior or guaranteed growth.
